# PRODUCT.md - Clone CRM Acto

## Product Truth

- **Name:** ERP Acto Dashboard Clone
- **Type:** Web Application (CRM Dashboard)
- **Purpose:** Clone pixel-perfect do dashboard do ERP Acto (https://actosfera-dev.acto.com.br)
- **Target Users:** Equipe interna da PW Labs

## Functional Requirements

1. Dashboard principal com cards de comunicação RH
2. Sidebar com menu de navegação completo
3. Header com busca global, notificações e perfil
4. Cards de aniversariantes do mês
5. Mural de novidades
6. Processos pendentes
7. Fila de notas fiscais
8. Projetos em risco

## Technical Stack

- Next.js 16.3.1
- React 19
- TypeScript
- Tailwind CSS 4
- Shadcn UI (Base UI)
- Phosphor Icons
